## Overview

Generate comprehensive audit reports for SuperAdmin activities, production changes, financial transactions, and user actions for compliance and governance.

## Business Value

### Problem Statement
- Activity logs exist but no easy way to generate audit reports
- Compliance audits require manual log extraction
- Cannot filter activity logs by user, date, or action type
- No export for external auditors
- SuperAdmin override activities not easily reviewable

### Expected Outcomes
- **Audit Readiness:** Generate compliance reports in <5 minutes
- **Transparency:** Complete traceability of all SuperAdmin actions
- **Compliance:** Meet regulatory requirements (SOC2, ISO 27001)

## Technical Design

### Server Actions

```typescript
generateAuditReport(config: {
  reportType: "superadmin_activity" | "production" | "financial" | "user_access" | "data_modification";
  startDate: Date;
  endDate: Date;
  filters?: {
    userId?: string;
    actionType?: string[];
    entityType?: string[];
    tenantId?: string;
  };
  format: "json" | "csv" | "pdf" | "xlsx";
}): Promise<{
  success: true;
  reportUrl?: string; // For PDF/Excel
  data?: any[]; // For JSON/CSV
  summary: {
    totalEntries: number;
    period: string;
    generatedAt: Date;
  };
} | {
  success: false;
  error: string;
}>
```

### Activity Log Query

```typescript
const activities = await prisma.activityLog.findMany({
  where: {
    createdAt: { gte: startDate, lte: endDate },
    userId: config.filters?.userId,
    type: { in: config.filters?.actionType },
    // Filter by SuperAdmin actions
    type: {
      startsWith: "SUPERADMIN_"
    }
  },
  include: {
    user: { select: { name: true, email: true, role: true } }
  },
  orderBy: { createdAt: "desc" }
});
```

### Report Generation

**PDF Generation (using jsPDF):**
```typescript
import jsPDF from "jspdf";
import autoTable from "jspdf-autotable";

function generatePDFReport(data: any[], config: ReportConfig) {
  const doc = new jsPDF();

  // Header
  doc.setFontSize(18);
  doc.text("Audit Report: " + config.reportType, 14, 20);
  doc.setFontSize(11);
  doc.text(`Period: ${formatDate(config.startDate)} - ${formatDate(config.endDate)}`, 14, 30);
  doc.text(`Generated: ${formatDate(new Date())}`, 14, 35);

  // Table
  autoTable(doc, {
    head: [["Date", "User", "Action", "Entity", "Details"]],
    body: data.map(row => [
      formatDate(row.createdAt),
      row.user.name,
      row.type,
      row.entityType || "-",
      JSON.stringify(row.details).substring(0, 50) + "..."
    ]),
    startY: 45
  });

  // Save
  const fileName = `audit-report-${Date.now()}.pdf`;
  doc.save(fileName);
  return fileName;
}
```

**Excel Generation (using exceljs):**
```typescript
import ExcelJS from "exceljs";

async function generateExcelReport(data: any[], config: ReportConfig) {
  const workbook = new ExcelJS.Workbook();
  const worksheet = workbook.addWorksheet("Audit Log");

  // Header row
  worksheet.columns = [
    { header: "Date/Time", key: "createdAt", width: 20 },
    { header: "User", key: "userName", width: 25 },
    { header: "Email", key: "userEmail", width: 30 },
    { header: "Action Type", key: "type", width: 30 },
    { header: "Entity", key: "entityType", width: 20 },
    { header: "Details", key: "details", width: 50 },
  ];

  // Data rows
  data.forEach(row => {
    worksheet.addRow({
      createdAt: formatDate(row.createdAt),
      userName: row.user.name,
      userEmail: row.user.email,
      type: row.type,
      entityType: row.entityType || "-",
      details: JSON.stringify(row.details, null, 2)
    });
  });

  // Styling
  worksheet.getRow(1).font = { bold: true };
  worksheet.getRow(1).fill = {
    type: "pattern",
    pattern: "solid",
    fgColor: { argb: "FFD3D3D3" }
  };

  // Save
  const fileName = `audit-report-${Date.now()}.xlsx`;
  await workbook.xlsx.writeFile(fileName);
  return fileName;
}
```
