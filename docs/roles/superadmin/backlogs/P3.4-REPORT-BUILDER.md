## Overview

Visual report builder for SuperAdmin to create custom reports with drag-and-drop fields, filters, and export options without code changes.

## Business Value

### Problem Statement
- Every new report request requires developer time
- Managers need ad-hoc reports for specific analyses
- Cannot combine data from multiple entities easily
- Export formats limited to CSV

### Expected Outcomes
- **Self-Service:** Managers create reports without developer help
- **Time Savings:** 85% reduction in report request turnaround
- **Flexibility:** Combine any data entities with custom filters

## Technical Design

### Architecture

**Pattern:** Metadata-driven query builder

**Components:**
1. **ReportBuilderCanvas** - Main builder interface
2. **FieldSelector** - Available fields from entities
3. **FilterBuilder** - Visual filter construction
4. **ReportPreview** - Live data preview
5. **SaveReportDialog** - Save template
6. **ScheduleReportDialog** - Email scheduling

### Report Metadata Schema

```prisma
model SavedReport {
  id          String   @id @default(cuid())
  name        String
  description String?
  createdBy   String
  config      Json     // Report configuration
  isPublic    Boolean  @default(false)
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt

  creator     User @relation(...)
}
```

**Config Structure:**
```json
{
  "entities": ["ProductionOrder", "Product", "Customer"],
  "fields": [
    { "entity": "ProductionOrder", "field": "orderNumber" },
    { "entity": "Product", "field": "name" },
    { "entity": "Customer", "field": "companyName" },
    { "entity": "ProductionOrder", "field": "quantity" }
  ],
  "filters": [
    {
      "field": "ProductionOrder.status",
      "operator": "in",
      "value": ["COMPLETED", "IN_PROGRESS"]
    },
    {
      "field": "ProductionOrder.createdAt",
      "operator": "gte",
      "value": "2025-01-01"
    }
  ],
  "joins": [
    { "from": "ProductionOrder.productId", "to": "Product.id" },
    { "from": "ProductionOrder.customerId", "to": "Customer.id" }
  ],
  "sort": [
    { "field": "ProductionOrder.createdAt", "order": "desc" }
  ],
  "groupBy": [],
  "aggregations": []
}
```

### Dynamic Query Builder

```typescript
async function executeReport(config: ReportConfig) {
  // Build Prisma query from config
  const query = buildPrismaQuery(config);

  // Execute query
  const results = await prisma[config.entities[0]].findMany(query);

  // Transform results based on selected fields
  return results.map(row => transformRow(row, config.fields));
}

function buildPrismaQuery(config: ReportConfig) {
  const where = buildWhereClause(config.filters);
  const orderBy = buildOrderBy(config.sort);
  const select = buildSelect(config.fields);
  const include = buildIncludes(config.joins);

  return {
    where,
    orderBy,
    select,
    include,
    take: 1000 // Safety limit
  };
}
```
