# P5.2: User Management Enhancement

**Priority:** 5 (High - Missing Core Feature)
**Estimated Effort:** Medium (3-4 days)
**Status:** Not Started
**Category:** User Management

---

## Overview

Enhance SuperAdmin user management capabilities to support full CRUD operations for users across all organizations. Currently SuperAdmin can only view users and reset passwords. This feature adds create, edit, and deactivate functionality with comprehensive audit trails.

## Business Value

- **User Lifecycle Management:** Complete control over user accounts from creation to deactivation
- **Emergency User Operations:** Quickly create accounts for new employees or contractors
- **Security Management:** Deactivate compromised or terminated user accounts
- **Compliance:** Proper user management with audit trails for regulatory requirements

## Current State vs Target State

### Current Capabilities ✅
- View all users (global)
- Reset user passwords
- View user activity logs

### Missing Capabilities ❌
- Create new users
- Edit user profiles and roles
- Deactivate/reactivate users
- Bulk user operations
- User role changes with validation

## User Stories

### Story 1: Create New User
**As a** SuperAdmin
**I want to** create new user accounts with specific roles and organization assignments
**So that** I can quickly onboard employees without waiting for normal registration workflows

**Acceptance Criteria:**
- Create user with email, role, and organization
- Auto-generate temporary password or send invitation email
- Assign to specific work centers (for workers)
- Set initial profile data (name, phone, emergency contact)
- Validate email uniqueness across system
- Require audit reason for SuperAdmin-created accounts
- Send welcome email with temporary credentials
- Force password change on first login

### Story 2: Edit User Profile and Role
**As a** SuperAdmin
**I want to** edit user profiles, roles, and assignments
**So that** I can correct mistakes or adjust user access levels

**Acceptance Criteria:**
- Edit all profile fields (name, phone, email, etc.)
- Change user role with validation
- Update organization assignment
- Modify work center assignments (for workers)
- Update inspector certifications (for inspectors)
- Require audit reason for role changes
- Cannot edit developer account
- Log all changes in activity log
- Validate role transitions (e.g., prevent invalid role changes)

### Story 3: Deactivate and Reactivate Users
**As a** SuperAdmin
**I want to** deactivate user accounts (soft delete) with reasons
**So that** I can disable access for terminated employees or security incidents

**Acceptance Criteria:**
- Deactivate user with mandatory reason (min 15 characters)
- Set deactivation date and deactivated by user
- User cannot login after deactivation
- Preserve all historical data and activity logs
- Reactivate users with reason
- Clear deactivation fields on reactivation
- Email notification to user (optional)
- Show deactivated users separately in list

### Story 4: Bulk User Operations
**As a** SuperAdmin
**I want to** perform bulk operations on multiple users
**So that** I can efficiently manage large teams or organization changes

**Acceptance Criteria:**
- Bulk deactivate users (e.g., mass layoff, contractor end)
- Bulk role change (e.g., promote multiple workers to supervisors)
- Bulk organization reassignment (e.g., restructuring)
- Preview changes before applying
- Single audit reason for bulk operation
- Transaction safety (all or nothing)
- Summary report after operation

### Validation Rules

**Email Validation:**
- Must be unique across all users
- Valid email format
- Cannot use developer email domain

**Role Change Validation:**
- Cannot change developer role
- Cannot assign SUPER_ADMIN role without special permission
- Validate role-specific requirements (e.g., workers need work centers)
- Log all role changes

**Deactivation Validation:**
- Cannot deactivate developer account
- Cannot deactivate own account
- Require active session
- Check for pending tasks/assignments

**Password Rules:**
- Auto-generated passwords: 16 chars, mixed case, numbers, symbols
- Must be different from previous passwords (future)
- Force change on first login
